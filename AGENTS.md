## Skills
A skill is a set of local instructions to follow that is stored in a `SKILL.md` file. Below is the list of skills that can be used in this repo.

### Available skills
- weekly-vibe-updater: Update one card in the Weekly Vibe Coding section of the Jiayang Wen portfolio. Use when the user wants to change the cover image treatment, title, description, emoji, try-out link, or README link for a weekly vibe block, or when the user wants Codex to draft those values directly from a GitHub repo README. (file: /Users/bryanwen/Documents/New project/jiayangwen/.codex/skills/weekly-vibe-updater/SKILL.md)

### How to use skills
- If the user names a skill or asks for a task that clearly matches one of the descriptions above, open that skill and follow it.
- Read only the files needed for the current task.
- Prefer the repo-local skill over inventing a new workflow for the same task.
